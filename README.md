# Newspaper Generator

A small web app for making fictitious newspaper pages: an editable A4 page with a header, footer and a flexible grid body, exportable as an image, PDF or JSON work file.

See [Spec.md](Spec.md) for the full specification.

Live site: https://mkocvara.github.io/newspaper-generator/

## Development

Built with Svelte 5, Vite and TypeScript.

```sh
npm install
npm run dev      # start dev server
npm run check    # type-check
npm run build    # production build to dist/
```

Pushing to `main` deploys to GitHub Pages via GitHub Actions.
